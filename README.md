# Cockpit

Web app stile CarPlay per lo scooter BMW C 400 GT: mappa con navigazione e traffico, radio italiane,
contatti (WhatsApp e telefono), meteo, calendario e un pulsante per la casa (routine Alexa).
Pensata per iPhone in orizzontale, aggiunta alla schermata Home.

**Apri:** https://antocanciello.github.io/Cockpit/ → Condividi → Aggiungi alla schermata Home.

- Tutta l'app è in `index.html` (niente build): GitHub Pages pubblica il ramo `main`.
- Contesto completo del progetto, scelte e convenzioni: [`CLAUDE.md`](CLAUDE.md).
- Prove automatiche: [`tests/`](tests/README.md).
